# Preflight

Проверка производственных файлов перед запуском в работу.
Читает папки сделок напрямую, ничего не загружает и не меняет.

## Установка

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск

```bash
python run_web.py
```

Откроется `http://127.0.0.1:8000`. При первом запуске — создание учётной записи.

Папки сделок ожидаются как `~/Desktop/Medali Store/<год>/<месяц>/<сделка (дедлайн)>`.
Другой путь:

```bash
PREFLIGHT_ROOT="/путь/к/папкам" python run_web.py
```

## Проверка из терминала, без интерфейса

```bash
python scan.py "путь/к/папке сделки"
python scan.py --all "путь/к/месяцу"
```

## Что где

| Файл | Назначение |
|---|---|
| `preflight/cdr.py` | чтение `.cdr` как ZIP: текст, цвета, палитра, превью, автор |
| `preflight/vector.py` | PDF и `.ai`: слои OCG, порядок, геометрия, рендер по слоям |
| `preflight/deal.py` | роли файлов в папке (финалка / рабочий / принт / рез / ленты / бэкап) |
| `preflight/spec.py` | инфо-блоки `ФОРМАТ ДЕТАЛИ…`, материалы, количества |
| `preflight/textcheck.py` | орфография, смешанные алфавиты, корпус своих слов |
| `preflight/checks.py` | правила и их серьёзность |
| `preflight/store.py` | SQLite: пользователи, прогоны, оценки, учёт сделок |
| `web/` | интерфейс |

База — `preflight.db` рядом с проектом. Корпус слов — `corpus.tsv`.
